# Sariaya-Town-Front-end-Website
HTML and CSS Showing the Beauty of Sariaya

## Run locally

Install [Node.js](https://nodejs.org/) if it is not already installed, then run:

```sh
node server.js
```

Open http://127.0.0.1:5500 in your browser. To use another port, set the `PORT`
environment variable before starting the server.
